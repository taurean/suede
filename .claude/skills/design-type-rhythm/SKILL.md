# Type rhythm

This skill owns how sizes and lines relate to each other. How type carries hierarchy in
product UI belongs to `product-design-typography`. Which token or layer a rule goes in
belongs to `writing-css`.

**[DTR-1]** Rhythm comes first. Settle it before layout details or colour, because uneven
text reads as low quality however good the rest is. Each role gets one size and one line
height, so body text is the same everywhere on the page, links and dates included.

**[DTR-2]** Choose line height for the job. Text that's always one line, like a control or
label, gets a line height of 1. Text that wraps gets a tight or loose line height.

**[DTR-3]** Small text needs proportionally more line height, because lines get hard to
tell apart. The ratio falls as text grows and inverts at very large sizes.

**[DTR-4]** Sizes relate to each other. Pick a heading size as a clear ratio of the body
size, such as twice the body, on a line height that relates to the body's line.

**[DTR-5]** Vertical spacing in text columns comes from the body's line height. Use whole
and fractional lines for the gaps between entries and sections.
