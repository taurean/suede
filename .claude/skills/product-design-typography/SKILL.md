# Product design typography

This skill owns how type carries hierarchy in a product interface. Which token or layer
a rule goes in belongs to `writing-css`.

**[PDT-1]** One text size does most of the work. Build hierarchy from colour and
placement first, and save a bigger size for what names the screen, like the page title.

**[PDT-2]** Weight stays quiet. Text is regular weight almost everywhere. Column headers
and other labels separate through muted colour and a tinted background, not bold.

**[PDT-3]** Icons match the text they sit beside: the same visual size, with a light
stroke, so the icon and its label read as one thing.
