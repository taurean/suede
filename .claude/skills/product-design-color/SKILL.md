# Product design colour

This skill owns how much strong colour a product interface uses, and what for. Which
token or layer a rule goes in belongs to `writing-css`.

**[PDC-1]** Strong colour is rare. The interface is neutral, and each strong colour has
one narrow job, like marking the primary action, a destructive action or a status.
