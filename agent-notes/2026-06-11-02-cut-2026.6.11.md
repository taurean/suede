## Decisions

- **Bump to `2026.6.11`, not `2026.6.13` +1.** chronver is the calendar date
  in `YYYY.M.D` form. Today is 2026-06-11 per the environment. The
  previously-tagged version (`2026.6.13`) is older than today and stays
  tagged — chronver does not require monotonic ordering of the calendar
  component, but a fork that cares can collapse on a later re-bump pass.
- **Single-commit release branch.** No code changes; only `package.json#version`
  + this task note. Follows the precedent set in
  `agent-notes/2026-06-05-06-cut-first-official-version.md`.
- **No changelog file.** `git log 2026.6.13..main` is the changelog, per
  AGENTS.md "Releases". The human runs that at tag time.
